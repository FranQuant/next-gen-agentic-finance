# AGENTS.md

Repository: agentic_finance

Purpose:
Agentic finance research examples combining LLM agents, financial data tools, and lightweight backtesting utilities.

Core technologies:
- AGNO agents
- OpenAI GPT models
- Tavily search
- YFinance
- Oanda market data
- Python research utilities

Architecture principles:
- keep examples minimal and runnable
- avoid hidden state
- keep financial utilities reusable
- separate agent orchestration from finance logic

Agent review priorities:

1. Repository architecture clarity
2. Code quality and modularity
3. Coherence between examples
4. Correct use of agents and tools
5. Quantitative research integrity

Quant research checks:
- avoid look-ahead bias
- avoid data leakage
- verify backtest assumptions
- ensure deterministic behavior when possible

Documentation checks:
- README instructions must match repository structure
- example scripts should run independently
