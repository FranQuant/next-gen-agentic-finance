# Phase A Scope

Phase A keeps this repo at Layer 1.

## In Scope

- Public or demo data retrieval.
- Bounded synthesis over retrieved data.
- Structured handoff for human review.
- Read-only tools and narrow example-level workflows.

## Out of Scope

- Data loading.
- Feature engineering.
- Backtests.
- Evaluation frameworks.
- Reporting stacks.

## Boundary

- Current repo = Layer 1 research intelligence.
- Next repo = future Layer 2.
- This repo stops at retrieval, bounded synthesis, and structured handoff.
- The future Layer 2 repo will handle data loading, feature engineering, backtests, evaluation, and reporting.
